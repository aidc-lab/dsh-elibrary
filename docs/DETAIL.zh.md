# 电子图书馆

一个安静的阅读角落，也是一个发现好书的窗口。

## 书架

- **导入图书**：支持 `.epub` 与 `.txt`，可一次选择多本。图书文件由本机 DSH Host 保存在 `~/.dsh/elibrary`，不会上传到任何服务器。
- **阅读**：EPUB 会读取目录、章节与插图，并以适合长时间阅读的排版呈现；TXT 会自动识别 UTF-8 / GB18030 编码并切分章节。
- **记忆阅读位置**：滚动、翻页或切换章节时都会记下当前位置。阅读进度保存在 Host 上，下次从书架打开，会直接回到你上次停下的地方。
- **整理**：按最近阅读、最近导入或书名排序，也可以搜索书名和作者。删除图书会同时移除本地的文件与阅读进度。

阅读界面支持目录跳转、上一章 / 下一章、字号、行距与衬线字体切换。

## 发现

- **豆瓣搜索**：输入书名、作者或关键词，搜索结果直接来自豆瓣。
- **豆瓣推荐**：浏览豆瓣当前推荐的书，可在同一行按主题、地区、排序调整。
- **筛选找书**：按主题、地区、排序筛选，适合漫无目的地逛。
- **图书详情**：点击任意一本，查看评分、简介、目录、出版信息与豆瓣条目链接。
## 榜单

- **总榜**：豆瓣每月热门图书榜与豆瓣读书 Top250，卡片直接展示前三名。
- **年度榜**：豆瓣 2025 / 2024 / 2023 年度读书榜单，按年度和分类查看完整十本。
- **类型榜**：外国小说、中国文学（非虚构）、推理、科幻、历史、科普、传记、戏剧、电影类图书等 Top100。
- **完整书单**：点开任意榜单查看排名、评分与出版信息，再点一本书进入豆瓣详情。

## 说明

- 所有豆瓣请求都由 DSH Host 转发，浏览器只访问本机的同源接口，不直接跨域请求豆瓣。
- 图片同样经过本地代理，以正常显示豆瓣封面。
- 图书与阅读进度存放在本机 `~/.dsh/elibrary`；可用环境变量 `DSH_ELIBRARY_DATA_DIR` 指定其他目录。
- 豆瓣接口属于非官方接口，可能随时调整；遇到加载失败时稍后重试即可。
