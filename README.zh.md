# 电子图书馆（dsh-elibrary）

给 DeepSeek Harness 加一个安静的阅读角落：左侧栏入口「电子图书馆」，包含书架、发现与榜单三个页面。

- **书架**：导入 `.epub` / `.txt` 图书，在应用内阅读，自动记住阅读位置。
- **发现**：搜索豆瓣图书，按主题、地区和排序浏览豆瓣推荐，查看图书详情。
- **榜单**：浏览豆瓣总榜、年度榜与类型榜，点开榜单查看完整书单。

## 结构

- `index.js`：Host 插件入口，注册同源 `/elibrary/api` 路由与访问校验。
- `lib/router.js`：接口路由，包含书架 CRUD、阅读进度、豆瓣搜索 / 推荐 / 详情 / 榜单与封面代理。
- `lib/library.js`：Host 端持久化书架，保存图书文件、解析后的元数据与阅读进度。
- `lib/douban.js`：豆瓣数据、年度榜单与封面代理。
- `client.js`：浏览器端脚本，负责侧栏入口、书架、阅读器、发现页、榜单页与 EPUB/TXT 解析。

## 安装

在 DSH 插件管理器中安装本目录，或在配置的 bundle 列表中加入 `dsh-elibrary`。安装后会注册一个 Host 行与一个浏览器入口。

## 说明

- 图书保存在本机 `~/.dsh/elibrary`（可用 `DSH_ELIBRARY_DATA_DIR` 覆盖），不会上传。
- 豆瓣请求由 Host 转发，浏览器只访问本机同源接口；封面也经过 Host 代理。
- 阅读进度保存在 Host 上，重启浏览器或刷新页面后仍可接着读。
- 支持格式：`.epub`、`.txt`。
- 豆瓣接口为非官方接口，可能随豆瓣调整而变化。
